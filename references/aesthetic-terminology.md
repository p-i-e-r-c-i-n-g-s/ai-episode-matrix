# Aesthetic terminology table

| Category | Examples | Prompt meaning |
|---|---|---|
| Capture format | 35mm, Super 35, 65/70mm, IMAX, medium format | scale, perspective, detail, depth, capture character |
| Lens system | spherical, anamorphic, vintage glass, modern sharp lens | distortion, bokeh, flare, compression, breathing |
| Emulsion influence | Ektar 100-like, Portra-like, Vision3-style | color, contrast, grain, skin, latitude; not guaranteed literal stock |
| Presentation format | IMAX 70mm, IMAX HD, Maxivision, theatrical digital | viewing scale, finishing, perceived clarity and impact |
| Finish/artifact | halation, bloom, gate weave, dust, scratches, grain | post/capture texture; use sparingly |

Ektar 100 and Portra are still-film references; describe observable qualities. IMAX HD, IMAX 70mm, and “Magic Carpet” are presentation/large-format references, not emulsion stocks. Maxivision is a motion-picture format/presentation reference. Director/movie associations are stylistic inferences, not automatic technical facts; verify production-specific claims before asserting them.
