# Reference-image analysis checklist

Before writing an image-to-video prompt, inventory the image as continuity state. Separate observations from inferences.

```text
SUBJECTS: count, identity cues, pose, gaze, expression
WARDROBE/PROPS: garments, materials, accessories, held objects
COMPOSITION: shot size, framing, camera height, angle, perspective, negative space
ENVIRONMENT: architecture, geography, foreground/midground/background layers
LIGHT: key direction, source, hardness, color, shadow shape, exposure priority
IMAGE: palette, contrast, depth of field, texture, artifacts, apparent format
SAFE TO ANIMATE: eyes, breath, gesture, cloth, hair, atmosphere, practical lights
PRESERVE: identity, anatomy, wardrobe, props, set geometry, composition, palette, light
RISKS: faces, hands, text/logos, reflections, thin structures, crowds, ambiguous anatomy
```

Do not claim to have inspected an image that is unavailable. If uncertain, mark `[VERIFY FROM IMAGE]`.
